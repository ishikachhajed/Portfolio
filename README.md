# 🌟 Ishika Chhajed Portfolio

A modern, responsive portfolio website built with **React, TypeScript, Vite, and Tailwind CSS** to showcase my projects, technical skills, achievements, and professional journey as a Software Developer.

🔗 **Live Portfolio:** [https://portfolio-theta-silk-nbb7k0b7ys.vercel.app/]

---

## 🚀 About

This portfolio serves as my personal digital space where I showcase:

* Software development projects
* Technical skills and technologies
* Resume and achievements
* Coding profiles and social links
* Contact information for collaboration opportunities

The website is designed with a clean user experience, interactive animations, and responsive layouts to provide a seamless experience across all devices.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)
* npm

### Installation

```bash
git clone https://github.com/ishikachhajed/Portfolio.git

cd Portfolio

npm install

npm run dev
```

Open:

```text
http://localhost:5173
```
